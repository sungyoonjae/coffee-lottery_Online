# 커피 제비뽑기 · 온라인 버전

떨어져 있는 사람들과 같은 카드판에서 커피 당번을 뽑는 웹앱입니다.
기존 오프라인 버전(25장 카드, 셔플·뒤집기 애니메이션, 폭죽)을 그대로 살리고 온라인 방 기능을 붙였습니다.

## 진행 방식

1. 방장이 닉네임을 입력하고 **새 방 만들기** → 4자리 방 코드가 생깁니다.
2. **초대 링크 복사**로 링크를 카톡·슬랙 등에 공유합니다. (또는 방 코드만 알려줘도 됩니다.)
3. 참가자는 링크를 열고 닉네임 입력 → **참가하기**.
4. 모두 들어오면 방장이 커피 살 사람 수를 정하고 **카드 섞기**.
5. 순서가 랜덤으로 정해지고, 자기 차례인 사람만 카드를 하나 뒤집을 수 있습니다.
   뒤집힌 카드에는 누가 뒤집었는지 이름이 표시됩니다.
6. 커피 사기 카드를 뒤집은 사람은 당첨 확정 후 순서에서 빠지고, 정해진 인원이 모두 나오면 끝!

- 커피 살 사람 수는 접속 인원보다 많게 설정할 수 없습니다.
- 자리를 비운 사람이 있으면 방장이 **차례 넘기기**로 넘길 수 있습니다.
- 게임 중간에 들어온 사람은 구경만 하고, 다음 판부터 참여합니다.

## 실행 / 배포

정적 파일(`index.html`, `style.css`, `script.js`)만으로 동작합니다. 서버가 필요 없습니다.

- **Netlify Drop**: 이 폴더의 파일들을 https://app.netlify.com/drop 에 드래그하면 바로 주소가 생깁니다.
- GitHub Pages, Vercel도 그대로 됩니다.

> 초대 링크는 웹에 배포한 주소에서만 동작합니다. `index.html`을 파일로 직접 열면 방 코드로만 참가할 수 있고,
> 다른 사람들도 같은 파일을 각자 열어야 합니다.

## 작동 원리 / 주의사항

- [PeerJS](https://peerjs.com)(WebRTC)로 브라우저끼리 직접 연결합니다. 처음 연결할 때만 PeerJS의 무료 공개 서버를 거칩니다.
- **방장 브라우저가 게임을 진행**합니다. 당첨 카드 위치는 방장 브라우저에만 있고, 참가자에게는 뒤집힌 카드의 결과만 전달되므로
  참가자가 개발자도구로 미리 볼 수 없습니다. (방장 본인은 마음먹으면 볼 수 있다는 점은 참고하세요.)
- **방장이 창을 닫으면 방이 종료**됩니다.
- 일부 회사·학교 네트워크는 WebRTC를 막아서 연결이 안 될 수 있습니다. 그럴 땐 휴대폰 핫스팟 등 다른 네트워크로 시도해보세요.
